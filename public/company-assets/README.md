# Company Assets

Esta carpeta contiene los assets de identidad corporativa de la empresa.

## Archivos requeridos:

### `logo.png`
- **Propósito**: Logo de la empresa para desprendibles y certificados
- **Formato**: PNG
- **Dimensiones recomendadas**: 300x100 px
- **Tamaño máximo**: 500KB
- **Fondo**: Puede ser transparente o blanco

### `signature.png`
- **Propósito**: Firma digital del representante legal
- **Formato**: PNG
- **Dimensiones recomendadas**: 200x80 px
- **Tamaño máximo**: 200KB
- **Fondo**: Preferiblemente transparente

## Instrucciones para actualizar:

1. **Para cambiar el logo**:
   - Reemplazar el archivo `logo.png` en esta carpeta
   - Mantener el mismo nombre de archivo
   - Reiniciar la aplicación si es necesario

2. **Para cambiar la firma**:
   - Reemplazar el archivo `signature.png` en esta carpeta
   - Mantener el mismo nombre de archivo
   - Los nuevos documentos mostrarán la firma actualizada

## Fallbacks:

Si no existen los archivos personalizados, el sistema usará:
- Logo por defecto: `/placeholders/default-logo.png`
- Firma por defecto: `/placeholders/default-signature.png`

## Notas importantes:

- Los archivos deben ser PNG para mejor calidad
- Mantener nombres exactos de archivos
- Hacer backup de archivos personalizados antes de actualizaciones del sistema
